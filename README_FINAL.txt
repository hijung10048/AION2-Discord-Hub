AION2 HUB v1.2 Final
====================

최종 기능
---------
- YouTube 5분 자동 알림
- 공지 5분 자동 알림
- 업데이트 5분 자동 알림
- 쿠폰 5분 자동 알림
- 점검 자동 분류/전용 채널 알림
- 서버별 중복 전송 방지
- /정보
- 설정 JSON 백업/복원

중요
----
기존 .env 와 aion2hub.db는 절대 삭제하지 마세요.
이 최종본은 기존 DB를 자동으로 마이그레이션하여
maintenance_channel_id 컬럼과 점검 전송기록 테이블을 추가합니다.

적용 순서
---------
1. 현재 봇을 Ctrl+C로 종료
2. 기존 AION2-Discord-Hub 폴더 전체 백업
3. ZIP 안의 .py 파일을 기존 폴더에 덮어쓰기
4. maintenance.py는 새 파일이므로 추가
5. 기존 .env / aion2hub.db 유지
6. 필요 시:
   python -m pip install -r requirements.txt
7. 실행:
   python main.py

처음 설정
---------
점검 알림을 받을 채널에서:
/점검채널설정

설정 확인:
/설정확인

새 명령어
---------
/정보
/점검채널설정
/점검테스트
/설정내보내기
/설정가져오기

설정 백업/복원
--------------
/설정내보내기:
현재 서버의 채널 ID + 채널명을 JSON 파일로 저장합니다.
봇 토큰/비밀번호는 포함되지 않습니다.

/설정가져오기:
JSON 파일을 첨부해서 복원합니다.
같은 서버에서는 채널 ID를 우선 사용하고,
다른 서버에서는 같은 이름의 채널이 있으면 그 채널로 복원합니다.
이름이 다른 채널은 "확인 필요"로 표시됩니다.

점검 자동 분류
--------------
최신 일반 공지 제목에 '점검'이 포함되면
일반 공지 채널로 중복 전송하지 않고 점검 전용 채널로 보냅니다.

주의:
점검채널이 미설정된 서버에서는 해당 점검 공지를 보내지 않습니다.

쿠폰 UI
-------
사용자가 선택한 기존 카드 디자인을 유지했습니다:
